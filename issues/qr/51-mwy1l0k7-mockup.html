Why did my QR code stop working? Your options explained

If your code redirects, you have three options

1. Ask the provider

Ask what happens to the code if you stop paying, and whether you can keep it live.

2. Reprint with a static code

Put the real address inside the pattern. It works as long as the page exists.

3. Cover it with a sticker

Stick a new static code over the old one, with no reprint of the whole item.

Questions

Is my code uploaded anywhere?

No. Decoding runs in your browser. We never receive the picture or what is inside.

Can the checker be wrong?

It can miss a redirect that uses an unlisted domain, and it may flag a short link that is fine. Treat it as a guide, and ask your provider if unsure.
