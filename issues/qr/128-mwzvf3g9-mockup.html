How to check

Before you reprint 500 flyers

A static code can never be edited, so make the printed link one you control.

The checklist

  1. Point the code at your own domain, not a vendor's.
  2. Use a short path like /menu that redirects.
  3. Print at least 2 × 2 cm, dark on light.
  4. Test-scan the printed proof on two phones.

Why a redirect helps

The printed link stays the same. The page it forwards to can change whenever you like.

yoursite.com/menu
→ yoursite.com/spring-menu-2027

Too dense to scan?

Long links make tiny, crowded squares. Shorten the link with a redirect on your own site, or print the code larger.
