Questions

How many codes can I make at once?

Up to 500 per batch. Everything is generated on your device, so very large lists may take a moment.

Do bulk codes expire?

No. Each is a static code with its content stored in the pattern itself.

What should my CSV look like?

One row per code: content first, then an optional file name and label. Download an example CSV.
