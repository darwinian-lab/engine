The one thing that can break your menu code

If your menu link changes, a static code breaks. Two ways to stay safe.

Fix 1: point it at a page you control

Print a code for a stable link, such as yourrestaurant.com/menu, then update what that page shows whenever the menu changes. The printed code never needs replacing.

Questions

Do menu QR codes expire?

No. A static code stores your menu link inside the pattern, so nothing can be switched off. It works as long as the link works.

Is it free?

Yes. Static codes are free with no account, no trial and no watermark.

Can I change the menu later?

Yes, if the code points to a page you control and you update that page. Or use an editable Pro code.

Do I need an app to scan?

No. Phone cameras scan QR codes natively.
