Wi-Fi QR code questions

Does a Wi-Fi QR code expire?

No. It is a static code with the details inside the pattern. It works until you change the network name or password.

Is it safe?

It is generated in your browser and never sent to us. But anyone who scans the code can read the password, so share it only where you would share the password.

How do I scan it on iPhone and Android?

Open the camera, point it at the code and tap the “Join network” banner. iPhone needs iOS 11+, Android needs 10+.

Does it work with WPA3?

Yes. Choose WPA/WPA2/WPA3; the code uses T:WPA, which phones accept for WPA3 networks.

What if my SSID has a semicolon?

We escape ; , : \ and " with a backslash, so “Café; Guest” becomes Café\; Guest inside the code.

Can I make a guest-network code?

Yes. Enter your guest network’s name and password and print the poster.
