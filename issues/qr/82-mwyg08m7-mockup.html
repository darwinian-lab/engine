Wedding QR code questions

Will the wedding QR code expire?

No. The code is static, so the link is stored in the pattern itself and we cannot switch it off. The album behind it is different: it stays online as long as your Google or Apple account and the album's sharing setting do.

Where should I put the code?

On the invitation (at least 2 cm square) and on table cards, with the link typed underneath for guests whose scan fails.

What if I change the album link later?

A printed static code cannot be edited. If you may swap the album, check the link first. Editable codes exist for that case, but most weddings do not need them.

Is it free?

Yes. No sign-up, no watermark, and free for commercial use.
