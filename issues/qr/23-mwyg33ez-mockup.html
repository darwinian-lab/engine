How to scan a WiFi QR code

iPhone (iOS 11+)

Open the Camera app and point it at the code. Tap the “Join network” banner, then Join.

Android

Open the camera, or Google Lens, and aim at the code. Tap the “Connect to network” prompt.

What you'll see

A banner with your network name, here “Harbour Cafe Guest”. No password is typed.

Security: the password is readable in the code

  • Anyone who scans the code can read the password. Use a guest network.
  • If the network is sensitive, don't leave the code in public view.
  • If you change the password, reprint the code.

Print tips

  • Minimum size about 2 cm (0.8 in). Bigger is easier to scan.
  • High contrast: dark code on a light background.
  • Matte paper avoids glare.
  • Keep a blank quiet zone around the code.
  • Test-scan a printed copy before you print many.

Questions

Does a WiFi QR code expire?

No. It's static, so it works as long as the network name and password stay the same.

Can I hide the password?

No. The password is stored inside the code, which is how phones join without typing. Use a guest network.

Does it work on iPhone and Android?

Yes. iPhone cameras on iOS 11 and later scan it, and so do Android cameras and Google Lens.

How do I make one for a hidden network?

Tick “Hidden network” before downloading.

Is it really free?

Yes. No signup, no watermark, no limit.

What happens if I change my password?

The old code stops joining the network. Make a new one and reprint.

Do you need a “dynamic” WiFi code?

No. WiFi codes hold the details themselves, so they don't need a server. Some sites sell dynamic WiFi codes, but you never need to pay for one.
