Do QR codes expire?

A static QR code never expires, because the URL or text is stored in the pattern itself. A dynamic QR code can stop working, because it points to the generator's server, and that service can switch it off if a trial ends or you stop paying.

Why QR codes stop working

Free trial ended

A dynamic code is switched off or redirected to a payment page.

Scan cap reached

Some plans limit scans, then stop redirecting.

Destination moved or deleted

The code still scans. The page it points to now shows an error. Keep the URL alive.

Low contrast or too small

Pale colours on a busy background, or a print under about 2 × 2 cm, are hard to read.

Questions

Do QR codes expire?

Static QR codes do not expire, because the data is stored in the pattern. Dynamic codes can stop working if the provider disables them.

Do free QR codes expire?

It depends on the type. A free static code never expires. A free dynamic code may stop when a trial ends, so check which one you have.

Can a QR code stop working after printing?

A static one will not stop. A dynamic one can. Any code can also fail if the page it links to is deleted, or if the print is too small or low contrast.

Do QR codes work forever?

A static code keeps scanning for as long as the print is readable. The page it links to must also stay online.

How long do they last?

A static code lasts as long as the print stays legible. A dynamic code lasts as long as the provider keeps it active.
