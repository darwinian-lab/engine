How it loads

The snippet reads the wall's card count and layout from one data attribute, so the placeholder is the right height from the first paint. Cards then fill that space without moving anything below.

<div data-kudos="lena-flow-yoga"
     data-cards="6" data-layout="wall"></div>
<script async src="https://kudospage.com/w.js"></script>

The one-line attribute is all the script needs to size the box.
